## Інформаційна система для дистанційного моніторингу стану слуху

#### Функціональні вимоги до системи включають наступне (роль «Лікар»):
1.	Вебзастосунок повинен давати змогу авторизуватися в системі.
2.	Вебзастосунок повинен давати змогу переглядати результати тестування конкретного користувача.
3.	Вебзастосунок повинен давати змогу переглядати результати аналізу за персональною та популяційною нормами користувача.
4.	Вебзастосунок повинен давати переглядати динаміку лікування за частотою у часі.
5.	Вебзастосунок повинен давати змогу написати повідомлення конкретному користувачу про необхідність повторного тестування чи корегування лікування.
6.	Вебзастосунок повинен давати змогу переглядати повідомлення, адресатом яких є авторизований користувач.
#### Функціональні вимоги до системи включають наступне (роль «Адміністратор»):
1.	Вебзастосунок повинен давати змогу реєстрації користувачів (пацієнта та лікаря) в системі.
2.	Вебзастосунок повинен давати змогу редагувати дані користувачів (пацієнта та лікаря) в системі.
3.	Вебзастосунок повинен давати змогу видаляти користувачів (пацієнта та лікаря) з системи.
4.	Вебзастосунок повинен давати змогу регенерування пароля користувачів (пацієнта та лікаря) в системі.
5.	Вебзастосунок повинен заборонити перегляд пароля користувача.
6.	Вебзастосунок повинен заборонити перегляд результатів тестування користувача (пацієнта).
